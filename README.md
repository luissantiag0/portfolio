# Luis Santiago — Portfolio Profesional

Portfolio web moderno de **Luis Santiago**, Desarrollador Web Junior y estudiante de DAW. Diseñado con un enfoque premium, accesible y responsive, mostrando proyectos reales, habilidades técnicas y trayectoria profesional.

## 🚀 Tecnologías

- **Framework:** React 19 + TypeScript
- **Build tool:** Vite 6
- **Estilos:** Tailwind CSS v4
- **Animaciones:** Framer Motion (motion/react)
- **Iconos:** Lucide React
- **Despliegue:** GitHub Pages / Vercel

## ✨ Características

- Diseño responsivo mobile-first con glassmorphism y efectos premium
- Terminal interactiva en hero con typewriter y tabs (profile / academic / compiling)
- Proyectos con imágenes reales, badges técnicos y análisis expandible (challenge + solution)
- Modal de CV imprimible con diseño tipo papel A4
- Formulario de contacto funcional con validación
- ScrollReveal animado en todas las secciones
- Modo oscuro / claro con transición fluida
- SEO optimizado con meta tags, Open Graph, Twitter Cards y Schema.org JSON-LD
- Favicon personalizado con símbolo de terminal

## 📁 Estructura

```
src/
├── assets/images/        # Imágenes de proyectos y portafolio
├── components/           # Componentes React
│   ├── Hero.tsx          # Hero con terminal interactivo
│   ├── Navbar.tsx        # Navegación con scroll progress
│   ├── Projects.tsx      # Grid de proyectos clickeables
│   ├── CVModal.tsx       # Modal de CV imprimible
│   ├── ContactForm.tsx   # Formulario de contacto
│   └── ...
├── context/              # LanguageContext (i18n español/inglés)
├── data.ts               # Datos estáticos de proyectos y skills
├── types.ts              # Tipos TypeScript
└── main.tsx              # Entry point
```

## 🌐 Idiomas

Español (por defecto) e Inglés. Cambio mediante el selector en la barra de navegación.

## 📦 Instalación

```bash

npm run dev
```
